# Princeton algs4 textbook examples

This directory preserves historical exercises that directly depend on Princeton's `edu.princeton.cs.algs4` textbook library.

They are intentionally outside `other/src/main/java` and therefore outside the default Maven reactor compile. They are not Algorithms V2 canonical implementations and must not drive production API or architecture decisions.

To run one of these examples manually, provide the official `algs4.jar` on the classpath as described by Princeton's Algorithms, 4th Edition site.
